## Ce que j'ai appris

Un dépôt est un dossier sur mon ordinateur et un site sur GitHub qui en garde tout l'historique.
Les branches permettent de travailler sans toucher à la version stable
Les commandes que j'ai utilisées sont : branch (pour créer une branche), commit (pour enregistrer une version avec un message), push (pour envoyer sur GitHub) et pull (pour récupérer les changements).
J'ai appris à modifier un fichier README, à y ajouter des images et à vérifier le résultat sur GitHub.
J'ai mis 2 heures pour réaliser ce travail.
